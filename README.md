# 🎬 Telegram Video & Audio Downloader Bot

Многофункциональный Telegram-бот для скачивания медиаконтента в максимальном качестве:
- 📺 **YouTube & YouTube Shorts**: скачивание от 360p до **1080p Full HD, 2K и 4K (2160p)**.
- 📱 **TikTok**: скачивание видео в высоком качестве без водяного знака (watermark).
- 📸 **Instagram**: Reels, посты с фото/видео, карусели (альбомы до 10 медиа) и Stories без водяных знаков.
- 🎬 **VK Видео и VK Клипы**: полноценная поддержка с выбором разрешения (1080p, 720p, 480p...).
- 📌 **Pinterest**: скачивание видео-пинов и картинок в оригинальном максимальном разрешении.
- 🐦 **Twitter (X)**: видео и гифки в наилучшем качестве со звуком.
- 🤖 **Reddit**: видео с автоматическим склеиванием видео и аудио потоков в наилучшем качестве.
- ⚖️ **Отображение веса**: динамический расчёт и показ примерного размера видео и аудио для каждого разрешения.
- 🎵 **Spotify-style MP3**: сохраняет аудио с **квадратной обложкой альбома (cover art)** и правильными ID3-метаданными (исполнитель, трек, альбом).
- 🎙 **Голосовое сообщение (ГС)**: конвертирует аудиодорожку в формат голосового сообщения Telegram (OGG Opus) с интерактивной аудиоволной.
- ✂️ **Нарезка по таймкодам**: вырезание нужного фрагмента видео или аудио (например `https://youtu.be/... 01:15-02:40`).
- 📑 **Плейлисты YouTube**: скачивание треков поштучно или единым ZIP-архивом.
- 🔍 **Инлайн-режим (Inline Mode)**: вызов бота в любом чате через `@имя_бота <ссылка>`.
- 🛡 **Обход блокировок YouTube (VLESS Reality)**: встроенный автономный менеджер туннеля на базе Xray-core (работает без прав root).
- ⚡️ **Скоростной MTProto (до 2 ГБ)**: многопоточная отправка файлов до 2 ГБ с живым анимированным прогресс-баром в чате.

## 🚀 Быстрый запуск

### Запуск на сервере (Linux / VPS):
```bash
git pull
pip install -r requirements.txt
python main.py
```

### Фоновый запуск (tmux / nohup):
```bash
# Через tmux:
tmux new -s bot
python main.py
# (Отключиться: Ctrl+B затем D. Вернуться: tmux attach -t bot)

# Или через nohup:
nohup python main.py > bot.log 2>&1 &
```

## 💡 Киллер-фичи

1. **Красивые обложки для MP3**:
   - При извлечении аудио бот скачивает оригинальный превью-арт, обрезает его в квадрат 1:1 (500x500) и вшивает в ID3v2 теги файла.
   - В Telegram аудио отображается с обложкой как в Spotify или Apple Music.

2. **Нарезка по таймкодам (Cut / Trim)**:
   - Отправьте ссылку вместе с таймкодом: `https://youtu.be/... 01:15-02:40`.
   - Или нажмите кнопку «✂️ Нарезать фрагмент» под сообщением с видео и отправьте отрезок времени.

3. **Плейлисты YouTube**:
   - Отправьте ссылку на плейлист: бот предложит скачать первые 5/10 треков по отдельности или упаковать их в ZIP-архив.

4. **Инлайн-режим**:
   - Напишите `@имя_бота <ссылка>` в любом диалоге или группе, чтобы поделиться медиа прямо в чате.
   - *(Для включения выполните команду `/setinline` у `@BotFather`).*
