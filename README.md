# 🎬 Telegram Video & Audio Downloader Bot

Многофункциональный Telegram-бот для скачивания медиаконтента:
- 📺 **YouTube & YouTube Shorts**: скачивание с интерактивным выбором качества (1080p Full HD, 720p HD, 480p, 360p).
- 📱 **TikTok**: скачивание видео в высоком качестве без водяного знака (watermark).
- 🎵 **Извлечение аудио (MP3)**: вырезает аудиодорожку из любого видео и сохраняет как MP3-трек с метаданными.
- 🎙 **Голосовое сообщение (ГС)**: конвертирует аудиодорожку в формат голосового сообщения Telegram (OGG Opus) с интерактивной аудиоволной и отправляет через `send_voice`.

## 🛠 Технологии и стек

- **Python 3.10+** (протестировано на Python 3.14)
- **aiogram 3.x** — современный асинхронный фреймворк для Telegram ботов
- **yt-dlp** — мощный инструмент для парсинга и загрузки видео/аудио
- **FFmpeg** — перекодирование видео и аудио, сведение потоков и создание Opus OGG для голосовых сообщений
- **Node.js** — задействован в yt-dlp для быстрого и безопасного обхода JavaScript-челленджей YouTube

## 💡 Особенности и обработка ограничений

- **Лимит Telegram (50 МБ)**:  
  Стандартный Bot API Telegram имеет ограничение на загрузку файлов размером не более 50 МБ.  
  Бот автоматически проверяет размер файла перед отправкой. Если видео в качестве 1080p превышает 50 МБ, бот вежливо предупредит об этом и предложит выбрать разрешение ниже (720p/480p) или скачать аудиофайл.
- **Голосовые сообщения**:  
  Аудио конвертируется строго по спецификации Telegram (`codec: libopus`, `sample_rate: 48000Hz`, `channels: 1 mono`, `bitrate: 64k`), поэтому Telegram распознает его как настоящее голосовое сообщение с визуальной звуковой волной.
- **Автоматическая очистка**:  
  Каждая загрузка выполняется в уникальной изолированной временной папке и удаляется сразу после отправки, не засоряя диск.
